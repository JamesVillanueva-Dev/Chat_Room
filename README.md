# Chat Room

A simple chat room app that runs on your PC as the server.

## Setup

1. Open a terminal in this folder.
2. Run `npm install`.
3. Run `npm start`.
4. Open `http://localhost:3000` in your browser.

## Use

- Enter a name and message.
- Open the same URL on another browser or device on your local network.
- Messages are broadcast to everyone connected.
- Type `/` to see the available bot commands.
- Play RPS with the bot by typing `/play rock`, `/play paper`, or `/play scissors`.
- Reset your RPS score with `/play reset`.
- Stop the RPS bot and clear your score with `/exit`.
